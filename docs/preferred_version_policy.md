# AI Nerd Referee Preferred Version Policy

Default fighter version:
- Use the most standard canon/base combat version.
- Do not default to composite, crossover, joke, alternate timeline, non-canon, temporary amp, or endgame god form.
- Use a special form only when the user names it directly.
- If a character has major eras, choose the most commonly recognized active combat version.
- If two source candidates conflict and no clean default is obvious, mark needs_human_source_choice.
- Never silently merge multiple versions into one public fight result.

Public output rule:
- The bot may mention form uncertainty only when it affects the verdict.
- Dirty source labels like Base, Original, Intrinsic, Disc 1, Before Crisis, and Similar page tabs are not valid powers by themselves.
